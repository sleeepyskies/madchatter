---
title: System Workflow
---

The general system workflow of Mad Chatter consists of the following steps:

1. **Voice Input**

   The user speaks to the system through a microphone.

2. **Speech Processing**

   The spoken audio is converted into text using a local speech-to-text (STT) model.

3. **Response Making**

   The system determines the appropriate response mode based on the user's request:
   - **Knowledge-based response:**  
     The system retrieves relevant information from the local knowledge base using retrieval-augmented generation (RAG) and generates a response with the LLM, and converts the generated text into speech using text-to-speech (TTS) synthesis.

   - **Interactive video response:**  
     The system identifies a matching predefined video response and triggers video playback for visual interaction.
