The only prerequisite is that python is installed. This is for the optional
setup scripts.

Mad Chatter is distributed as a standalone binary for Windows, macOS, and Linux.
Download the correct release for your OS from the GitHub page.

After downloading:

1. Extract the ZIP archive.
2. Move the extracted folder wherever you want.
3. Start the application.

---

## Starting MadChatter

The recommended way to start Mad Chatter is currently through the command line.

Some reasons are:

- Application logs
- Better visibility into startup errors
- Better control over application lifetime (closing the browser tab doesn’t
shut down the application)

To run MadChatter, simply run the following command in a console.

<CodeTabs>
    ```powershell
    [install-directory]\madchatter\madchatter.exe
    ```

    ```bash
    [intall-directory]/madchatter/madchatter
    ```
</CodeTabs>

## Initial Setup

Mad Chatter includes an optional setup script for preparing required runtime dependencies.

The setup script will check the presence of any hard requirements, and
optionally install any optional requirements.
Running the setup script is recommended on a fresh installation.

The setup script can be run by running the following command:

<CodeTabs>
    ```powershell
    python [install-directory]\scripts\setup.py
    ```

    ```bash
    python [install-directory]/scripts/setup.py
    ```
</CodeTabs>

The flag `--defaults` can be passed in when running the script to also
fetch some default models:

<CodeTabs>
    ```powershell
    python [install-directory]\scripts\setup.py --defaults
    ```

    ```bash
    python [install-directory]/scripts/setup.py --defaults

    ```
</CodeTabs>

## Adding new Piper voice models

In order to add new voice models, you must provide the files yourself. This can
be done by:

- Downloading the `voice-model.onnx` and `voice-model.onnx.json` files (some
can be found under [piper-samples](https://rhasspy.github.io/piper-samples/)).
- Placing both the files in either the `de` or `en` directory at `madchatter/run/voice-models`.
