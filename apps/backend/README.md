# madchatter - backend

Official package for the Mad Chatter backend.

## Overview

The Mad Chatter backend is a FastAPI based web server. It follows the general pattern of an API layer, a Service layer
and a database layer.

## Running the project

Make sure to have python and uv installed.

Create a `.env` file using the `.env.example` template at the root of the repository. This is shared
between the frontend and backend.

Run `uv run src/main.py` to start the server.
