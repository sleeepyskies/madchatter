# MadChatter

## Documentation

Documentation can be found [here](https://madchatter.pages.dev) (site is still under
construction).

## Requirements

In order for the web application to run, make sure that the `ollama` is installed onto the system.
The following manifests must also be pulled using `ollama`:
1. `jina/jina-embeddings-v2-base-de`
2. `llama3.2`
